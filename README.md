Expense Tracker Application (Python)

Project Overview
The Expense Tracker is a console-based Python application developed using Object-Oriented Programming (OOP). It helps users record, manage, and track their daily expenses efficiently. Users can add, view, search, and delete expenses while monitoring their total spending.

Objectives
- Simplify daily expense management.
- Track expenses category-wise.
- Automate total expense calculations.
- Improve personal financial management.

Technologies Used
- Programming Language: Python
- Concepts: Object-Oriented Programming (OOP)
- Data Structures: Lists and Dictionaries

Key Features
- Add new expenses.
- View all recorded expenses.
- Calculate total expenses automatically.
- Search expenses.
- Delete expense records.
- Manage expenses category-wise.
